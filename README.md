# 丢纸团儿

一个可以键盘打字、鼠标手写、揉纸、扔到地上再捡回的交互页面。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端中显示的本地网址。构建：`npm run build`；预览构建：`npm run preview`。

## 操作

- 纸上打字；切到手写可用鼠标、触屏画线。橡皮擦除整条笔迹，撤销恢复上一步笔迹。
- 「工整 → 凌乱」连续调整字符的倾斜、位置、大小和字重；不改变手写内容。
- 点纸下方「写完了」，按住纸张揉皱，拖动松手后投掷；「帮我扔掉」为替代操作。
- 点击地上的纸团捡回并展开，只读查看；点击纸面再次揉成团，可拖动投掷。另一张编辑中的纸会暂存。
- 本地浏览器自动保存，不上传文字或笔迹。清扫需要确认。
- 不在输入框中时，T 切换打字，P 切换手写；手写时 Ctrl/Cmd+Z 撤销；颜色圆点打开饱和度/明度面板与色相滑轨，支持十六进制颜色。

## 实现

React + Vite + Three.js，图标使用 Lucide。揉纸变形求解器从用户提供的 React Bits PaperCrumple 源码中提取，原始组件保留在 `src/OriginalPaperCrumple.jsx`，实际页面在单一 Three.js 场景中扩展投掷、落地和拾取。日常投掷、落地、滚动和清扫共用碰撞求解器。以纸团变形网格的外接球作为保守碰撞体，使用自适应子步、接触分离、冲量、摩擦和滚动旋转避免纸团互相穿透；移动后同步拾取区域及本地保存位置。清扫时允许纸团滚出右侧边界，全部离开后移除。文字效果是可读的程序化排版变化，不是生成新的手写字形。

界面会尝试加载 Google Fonts 的 Noto Serif SC，网络不可用时回退到系统宋体；纸面使用系统楷体或宋体。WebGL 不可用时保留书写功能并提示。

## 已验证

生产构建；真实浏览器中的中文打字、滑轨、手写、鼠标揉纸投掷、落地、拾取展开、另一张纸暂存、刷新恢复和 390px 窄屏。


## GitHub Pages 部署

把整个项目上传到 GitHub 的 `main` 分支，GitHub Actions 会自动构建并发布。仓库设置中将 Pages 的 Source 设为 **GitHub Actions**。发布地址为 `https://用户名.github.io/仓库名/`。
